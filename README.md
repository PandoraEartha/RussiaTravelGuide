# 实用信息和注意事项

可以在[白俄罗斯铁路官网](https://pass.rw.by/ru/)购买和查看俄罗斯火车票, 如果某趟车有票但无法购买可以将车次时刻和车厢座位发给留学生代定. 越晚定越贵. 

可以在 https://www.tutu.ru/ 网站查看列车的座位铺位信息以及评价

入境时给的小白条一定要保存至出境

旅行超过7天必须在酒店办理居住证明, 且办理后的7天内必须重新办理或者更新, 更换城市的时候可能会查看上一个城市的居住证明. 该居住证明在小红书上俗称"落地签", 但不要将其翻译成俄语给前台看, 请直接给前台看居住证明或者"落地签"的图片. 

莫斯科市区定位会漂, 打车或导航请确认起点正确

博物馆有免费日, 可以酌情调整攻略

星期天早上去教堂碰见礼拜可能免票

博物馆不能带双肩包, 建议携带一个小包, 准备充电宝, 水和食物

如果需要从俄罗斯出/入境白俄罗斯, 请详细查看相关攻略和注意事项

火车票注意查看是当地时间还是莫斯科时间

去武装力量大教堂如果需要乘坐75路公交车, 记得在公交卡内保留至少150卢布(单程票好像是73卢布)

俄罗斯出入境通关较慢, 一定要留足时间, 建议提前三个小时到机场

女性需要准备头巾, 一些教堂需要戴头巾

莫斯科IP无法打开去哪儿, 可以准备VPN

SVO到市区的1195路车可以买双程票

莫斯科或其他俄罗斯欧洲城市可能因为战争关闭机场, 请规划好相应交通, 留出缓冲时间
